Next Button Test

Test Instructions

1. Open the application at http://localhost:8089

2. Log in as a learner

3. Navigate to a course

4. Open a lesson

5. Click the "Next Lesson" button

6. Check the browser console for debug messages

Expected Behavior

  • The next button should be enabled (not grayed out)
  • Clicking the button should complete the current lesson
  • After completion, it should navigate to the next lesson
  • Console should show debug messages with 🔄, ✅, and ➡️ emojis

Debug Messages to Look For

🔄 Next lesson button clicked: {isCompleted: false, isLastLesson: false, ...} 📚 Lesson not completed, completing it first... 📊 Completing lesson (timer restrictions disabled for testing): {...} ✅ Lesson completed, proceeding to next lesson ➡️ Moving to next lesson... 🔄 LearnerDashboard handleNextLesson called: {...} 🔄 Navigating to next lesson: {currentIndex: 0, totalLessons: 5, ...} ➡️ Moving to next lesson: "Lesson Title" Order: 2 Completed: false

Common Issues

  • Button is disabled: Check if isLoadingCompletionStatus is true
  • No navigation: Check if onNextLesson is properly passed to LessonViewer
  • Lesson not completing: Check if handleCompleteLesson is working
  • Wrong lesson order: Check if lessons have proper order property
